# Xianxia Cultivator NFT Metadata

This repository publishes the Xianxia Cultivator NFT collection assets and ERC-721-compatible metadata.

- `images/` — square WebP avatar images
- `metadata/` — 1,111 JSON metadata files, named `1.json` through `1111.json`

Directory-mode metadata base URL:

`https://raw.githubusercontent.com/tomzlabs/xianxia-cultivator-nft-1111/main/metadata/`

Each metadata document links to the matching image as `images/xianxia-0001.webp` etc. The present artwork batch contains tokens `#0001`–`#0459`; the remaining metadata paths are already reserved for the matching images as the artwork generation continues.
